# Sampled Data

전체 원본 데이터에서 프로젝트 분석 및 모델링 대상으로 추출한 표본 데이터를 저장한다.

## 표본 추출 기준

- `train_v2`의 `is_churn` 비율을 유지하는 층화 추출을 사용한다.
- 최대 100,000명의 고객을 추출한다.
- 재현성을 위해 `random_state=42`를 사용한다.
- 추출된 고객의 `msno`를 기준으로 회원·거래·이용 로그를 필터링한다.

## 활용 목적

- 대용량 데이터 처리 시간 단축
- EDA 및 전처리 수행
- 고객 단위 통합 데이터 생성
- 머신러닝·딥러닝 모델 학습

## 주의사항

- 표본 추출 코드를 통해 재생성할 수 있어야 한다.
- 표본 데이터 파일은 Git에 업로드하지 않는다.
- 최종 전처리·통합 데이터는 `data/processed/`에 저장한다.
