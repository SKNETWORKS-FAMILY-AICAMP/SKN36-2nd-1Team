# Processed Data

원본 데이터를 전처리하고 고객 단위로 통합한 모델링 데이터를 저장한다.

## 파일 구성

| 파일명 | 설명 |
|---|---|
| `integrated_data.csv` | 회원·거래·이용 로그를 `msno` 기준으로 통합한 모델링 데이터 |

## 처리 기준

- 고객 식별자인 `msno`를 기준으로 데이터를 결합한다.
- 피처 관측 기준일은 `2017-02-28`로 설정한다.
- 예측 대상 기간은 `2017-03-01`부터 `2017-03-31`까지이다.
- `is_churn`을 모델의 타깃으로 사용한다.
- 거래 및 이용 로그는 고객 단위로 집계한다.

## 주의사항

- 직접 수정하지 않고 전처리 코드를 통해 다시 생성한다.
- 모델 학습 및 서비스 예측 시 동일한 피처 정의를 사용한다.
- 생성된 CSV 파일은 Git에 업로드하지 않는다.
